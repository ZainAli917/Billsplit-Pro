## ✨ Features

- 👥 **Groups** — Create groups for trips, flatmates, friends
- 💸 **Smart Split** — Equal, Percentage, or Exact amount
- 🧮 **Min-Cash-Flow** — Least transactions to settle up
- 📸 **Receipt Photos** — Attach receipt to any expense
- 💬 **WhatsApp Share** — Share settlements instantly
- 🔔 **Notifications** — Track all activity
- 📤 **Backup & Restore** — Export/import your data
- 🌐 **Offline** — Works without internet
- 📱 **Installable** — Add to home screen (PWA)

## 🚀 Deploy on Netlify (Free)

1. Fork this repo
2. Go to [netlify.com](https://netlify.com)
3. Click **"New site from Git"**
4. Select this repo
5. Deploy! ✅

Or drag & drop folder on [drop.netlify.com](https://drop.netlify.com)

---

## 📱 Convert to APK (Android)

1. Deploy on Netlify first
2. Go to [pwabuilder.com](https://pwabuilder.com)
3. Enter your Netlify URL
4. Click **Android** → Download APK
5. Install on Samsung/Android! ✅
